# moo-ping-wiriya-front

เว็บไซต์ร้านหมูปิ้งวิริญา (Next.js + Tailwind)

```bash
npm install
npm run dev
```

เปิดที่ http://localhost:3003 (ตั้งพอร์ต 3003 ไว้ใน `package.json` เพื่อไม่ชนกับเว็บอื่นของครอบครัว)

- ข้อมูลร้าน เมนู ราคา เบอร์โทร รูป: `src/data/site.ts`
- รูปจริงจากหน้าร้าน: `public/images/`
