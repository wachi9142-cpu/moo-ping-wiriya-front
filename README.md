# หมูปิ้งวิริญา — Wiriya Moo Ping

เว็บไซต์ร้านหมูปิ้งวิริญา · Next.js 16 + React 19 + Tailwind v4 + TypeScript

เอกสารนี้เขียนให้คนที่มารับงานต่อ อ่านจบแล้วควรรันและแก้ของได้เลย
สเปก API ฉบับละเอียดอยู่ที่ [`API.md`](./API.md)

---

## เริ่มต้น

ต้องมี Node 22 ขึ้นไป (ใช้ `node:sqlite` ที่ติดมากับ Node — ไม่ต้องลง database แยก)
เครื่องที่พัฒนาไว้ใช้ Node v25.8.2

```bash
npm install
cp .env.example .env.local   # แล้วแก้ค่าข้างใน (ดูหัวข้อ "ตัวแปรลับ")
npm run dev
```

เปิดที่ **http://localhost:3003**

พอร์ต 3003 ตั้งตายตัวไว้ใน `package.json` เพราะเครื่องเจ้าของมีเว็บอื่นของครอบครัว
รันอยู่ที่ 3000 อยู่แล้ว ถ้าพอร์ตชนให้เช็กว่ามีโปรแกรมอื่นยึดไว้หรือเปล่า

```bash
npx kill-port 3003
```

| --- | --- |
| `npm run dev` | รันโหมดพัฒนา |
| `npm run build` + `npm start` | รันโหมดจริง |

## โครงหน้าเว็บ

`src/app/page.tsx` ประกอบจาก component ใน `src/components/` ตามลำดับ

```
Hero      #top       ชื่อร้าน + รูปใหญ่ + สถานะเปิด/ปิด + ปุ่มโทร
Menu      #menu      หมูปิ้ง / ข้าวเหนียว พร้อมป้ายราคา
Gallery   #gallery   แกลเลอรีรูปหน้าร้าน (แอดมินอัปโหลดได้)
Location  #location  แผนที่ + เบอร์เจ้าของร้าน
Hours     #hours     เวลาขาย
Reviews   #reviews   รีวิวลูกค้า (ดึงจาก API)
Laundry   #laundry   เครื่องซักผ้าหยอดเหรียญ
```

`TopBar`, `Footer`, `FloatingCall` อยู่ใน `src/app/layout.tsx` (มีทุกหน้า)

สถานะ "กำลังขาย / ปิดแล้ว" คำนวณจากเวลาไทยใน `src/lib/useOpenNow.ts`
เทียบกับ `site.open` และ `site.closeApprox` — ยังไม่ใช่สวิตช์ที่แอดมินกดเอง

## ระบบหลังบ้าน

ทำไว้ในตัว Next.js เอง (API routes + SQLite) ไม่ได้แยกเซิร์ฟเวอร์

```
src/app/api/     API routes ทั้งหมด
src/server/db.ts       เปิดฐานข้อมูล + สร้างตาราง
src/server/session.ts  ล็อกอินแอดมิน (cookie เซ็นด้วย HMAC)
src/lib/api.ts         ฝั่ง client เรียก API ผ่านที่นี่ที่เดียว
```

**สิ่งที่เก็บในฐานข้อมูล** — รีวิวลูกค้า และรูปที่แอดมินอัปโหลด
ที่เหลือฮาร์ดโค้ดใน `src/data/site.ts`

เข้าหน้าแอดมินที่ **`/admin`** — อนุมัติรีวิว และเมื่อล็อกอินแล้ว
ปุ่มเพิ่ม/เปลี่ยน/ลบรูป จะโผล่ที่แกลเลอรีในหน้าแรก

### ที่เก็บข้อมูล

```
data/wiriya.db    ฐานข้อมูล SQLite
data/uploads/     ไฟล์รูปที่อัปโหลด (อยู่นอก public/ จึงเสิร์ฟผ่าน API route)
```

โฟลเดอร์ `data/` อยู่ใน `.gitignore` — **สำรองข้อมูล = copy โฟลเดอร์นี้ทั้งอัน**
ลบโฟลเดอร์นี้ = รีวิวและรูปที่อัปโหลดหายหมด (รูปใน `public/images/` ไม่หาย)

### ตัวแปรลับ

`.env.local` (ไม่ขึ้น git) ต้องมี 3 ค่านี้

```
NEXT_PUBLIC_SITE_URL=http://localhost:3003
ADMIN_PASSWORD=<รหัสผ่านเข้าหน้า /admin>
ADMIN_SESSION_SECRET=<ค่าสุ่มยาว ๆ>
```

สุ่ม secret ใหม่:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

ถ้าเปลี่ยน `ADMIN_SESSION_SECRET` คนที่ล็อกอินค้างไว้จะหลุดทั้งหมด

## สถานะงาน

### ทำเสร็จแล้ว

- หน้าเว็บครบทุกส่วน responsive ตั้งแต่มือถือ 375px ถึงจอคอม
- รีวิว: ลูกค้าส่ง → เข้าคิวรออนุมัติ → แอดมินอนุมัติ → ทุกคนเห็น
- อัปโหลด/เปลี่ยน/ลบรูปหน้าร้านจากหน้าเว็บ
- ล็อกอินแอดมิน กัน endpoint ที่ต้องเป็นแอดมิน (ตอบ 401)
- SEO/แชร์ลิงก์: Open Graph, favicon, หน้า 404

### งานที่ยังไม่ได้ทำ

1. **ให้เจ้าของร้านแก้ราคา/เวลา/เบอร์โทรเองได้** — สำคัญที่สุด
   ตอนนี้ต้องแก้ `src/data/site.ts` แล้ว deploy ใหม่ทุกครั้ง
2. **ปุ่ม "วันนี้ของหมดแล้ว"** ให้แอดมินกดเอง — ตอนนี้ดูจากเวลาอย่างเดียว
3. **แอดมินหลายคน** — ตอนนี้รหัสผ่านเดียว ไม่มี log ว่าใครทำอะไร
4. **กันสแปมรีวิว** — ยังไม่มี rate limit หรือ captcha
5. **⚠️ รีวิวตัวอย่างเป็นรีวิวที่แต่งขึ้น** — `reviews` ใน `src/data/site.ts`
   จะโชว์ตอนที่ยังไม่มีรีวิวจริงในฐานข้อมูล (ดู `src/components/Reviews.tsx`)
   ลูกค้าที่เข้ามาดูจะเข้าใจว่าเป็นรีวิวจริง
   **ก่อนเปิดใช้งานจริงควรลบทิ้ง** แล้วให้ขึ้นว่ายังไม่มีรีวิวแทน
6. **ยังไม่ได้ deploy** — รันอยู่บน localhost เท่านั้น คนอื่นยังเข้าไม่ได้

## ตอน deploy

- ต้อง set `ADMIN_PASSWORD`, `ADMIN_SESSION_SECRET`, `NEXT_PUBLIC_SITE_URL` บนเซิร์ฟเวอร์
- ต้องมีที่เก็บไฟล์ถาวรสำหรับโฟลเดอร์ `data/` — ถ้า deploy บนแพลตฟอร์มที่ดิสก์
  หายทุกครั้งที่ deploy (เช่น Vercel) **รีวิวและรูปจะหาย** ต้องย้ายไปใช้
  database กับ object storage ข้างนอกแทน
- cookie แอดมินตั้ง `secure` อัตโนมัติเมื่อ `NODE_ENV=production` จึงต้องเปิดเว็บผ่าน HTTPS
- ถ้ารูปย้ายไปโดเมนอื่น ต้องเพิ่ม `images.remotePatterns` ใน `next.config.ts`
